# ♻ ReWear – Sustainable Clothing Reuse Platform

ReWear is a web-based platform that helps people **reuse, recycle, and redistribute clothes** in an eco-friendly way.  
The system connects **Sellers, Manufacturers, Delivery Partners, and Customers** to reduce textile waste and promote sustainability.

---

# 🚀 Project Overview

ReWear allows users to donate or sell clothes instead of throwing them away.  
Manufacturers review the clothes and approve them for pickup.  
Delivery partners collect the clothes and deliver them to the recycling center.

This system helps:

- Reduce textile waste
- Promote sustainable fashion
- Create an eco-friendly clothing lifecycle

---

# 👥 User Roles

### 1️⃣ Customer
- Create an account
- Browse available clothes
- Purchase sustainable clothing

### 2️⃣ Seller
- Create seller account
- Upload cloth details with image
- Track approval status

### 3️⃣ Manufacturer
- Review seller cloth submissions
- Accept or reject clothes
- Create pickup requests

### 4️⃣ Delivery Partner
- View available pickups
- Accept pickup requests
- Track delivery tasks
